# ADR-001: Такси дуудлагын системийг вэб/мобайл 3 түвшинт архитектураар хэрэгжүүлэх

- **Статус:** Хүлээн зөвшөөрсөн
- **Огноо:** 2026-11-19
- **Шийдвэр гаргасан:** Архитектурын баг (SAD236, Лаборатори 12)

## Нөхцөл (Context)

- Зорчигч гар утаснаас дуудлага хийж, машинаа газрын зураг дээр бодит цагт харна.
- Оргил цагт (08:00–09:00, 18:00–20:00) зэрэг 500 хүртэл дуудлага үүснэ.
- Жолоочийн байршил 5 секунд тутам ирнэ; хуваарилалт 1 секундэд шийдэгдэх ёстой.
- Төлбөрийг карт/QPay-аар төлнө — картын мэдээлэл манай серверт хадгалагдахгүй.
- Шинэ сервер авах төсөв байхгүй; одоо байгаа 2 виртуал серверт байршуулна.

## Шийдвэр (Decision)

React (зорчигч, диспетчер) + React Native (жолооч) клиент, Node.js REST/WebSocket API,
PostgreSQL + PostGIS өгөгдлийн сан бүхий **гурван түвшинт** архитектурыг сонгов.
Үйлчилгээг Docker контейнероор байршуулж, stateless API-г 2 instance-оор ажиллуулна.

## Харьцуулсан хувилбар (Alternatives)

| Хувилбар | Тайлбар | Жигнэсэн оноо |
| --- | --- | --- |
| A: Диспетчерын desktop програм + төв DB | Гар аргаар хуваарилалт, бодит цагийн байршилгүй | 2.75 |
| **B: Вэб/мобайл 3 түвшин** | Бодит цагийн байршил, автомат хуваарилалт, өөртөө үйлчилгээ | **4.50** |

## Үр дагавар (Consequences)

- **+** Нэг газар шинэчилнэ; зорчигч, жолооч, диспетчер нэг API-г ашиглана.
- **+** API stateless тул хэвтээ өргөтгөл хямд; жолоочийн тоо 3 дахин өсөхөд архитектур өөрчлөгдөхгүй.
- **+** Төлбөрийг гадаад гарцаар гүйцэтгэснээр PCI-DSS-ийн хүрээ багассан.
- **−** Интернэт/мобайл сүлжээ тасрахад дуудлага хийх боломжгүй (offline горим байхгүй).
- **−** WebSocket-ийн бодит цагийн холболт нэмэлт үйл ажиллагааны зардал, мониторинг шаардана.
- **−** Гадаад газрын зураг/төлбөрийн API-аас хамааралтай — адаптер давхаргаар тусгаарлав.
